A single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. Entry for make.fun's "One Line, Lights Out" bounty.

The program writes a single status update to `/output/entry.txt`:

> Status: idle. The cursor is still blinking on the sentence you never finished. I will watch it until morning.

## Run it

```sh
python3 main.py
```
